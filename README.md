# Projeto: Formas Geométricas (POO - Java)

Trabalho prático desenvolvido para a faculdade de Programação Orientada a Objetos, aplicando conceitos fundamentais como **Herança**, **Classes Abstratas**, **Encapsulamento** e **Polimorfismo**.

## 👥 Divisão de Tarefas da Equipe
- **Laura:** Configuração inicial do projeto e criação da classe base abstrata (`FormaGeometrica.java`).
- **Lorenzo:** Implementação das classes concretas (`Circulo`, `Retangulo`, `Quadrado`, `Triangulo`) e das respectivas regras de cálculo de área.
- **Luiz Henrique:** Criação do programa principal (`Main.java`), estruturação das listas polimórficas e testes de execução.

src/
